# 真机回归清单（Android / iOS）

> 体验蓝图 Phase D · 手工 QA。发布原生包前至少跑一遍。  
> 工程发版门禁见 `docs/android-release-checklist.md`。

## 登录与键盘

- [ ] 首次安装：登录页安全区、品牌 Hero、服务器折叠摘要
- [ ] 键盘弹起：输入框与「登录」按钮不被挡；无底部白条
- [ ] 记住密码 / 自动登录（若平台支持）
- [ ] 2FA 面板关闭与返回

## 系统分享入站（Android Phase A）

- [ ] 浏览器 / 微信「分享 → 蜉蝣」文本：生成笔记并打开
- [ ] 分享 `mp.weixin.qq.com` 链接：走剪藏导入
- [ ] 分享单图 / 多图：笔记内嵌图
- [ ] 未登录时分享：提示登录后自动保存；登录后落库
- [ ] 冷启动分享（App 未在前台）：同样能保存

## 后台保活与通知（Android Phase B）

- [ ] 冷启动默认**无**「后台消息」常驻通知
- [ ] 设置 → 关于 → 开启「后台消息提醒」后出现低优先级常驻通知
- [ ] 关闭开关后常驻通知消失
- [ ] 系统通知设置可见：任务提醒 / 消息与提及 / 后台同步 三渠道
- [ ] 任务提醒走「任务提醒」渠道（可单独静音）

## 媒体 / 下载 / 权限（Android Phase C）

- [ ] 播放音频后出现「媒体播放」渠道常驻通知；含上一曲/播放暂停/下一曲/停止
- [ ] 通知栏暂停/下一曲能控制 App 内播放
- [ ] 停止或退出曲目后媒体通知消失
- [ ] 附件下载（大文件）不白屏/不 OOM，落在系统下载目录
- [ ] 分享笔记链接：系统分享 sheet 可用
- [ ] 拒相机权限后可跳转系统设置

## 壳层 / 网络 / 字体 / 分屏（Android Phase D）

- [ ] 断网：顶部出现「网络不可用」横条；右下可显示待同步
- [ ] 恢复网络：短暂「已恢复连接」；待同步可点刷新
- [ ] 从后台回前台：网络状态及时刷新（不必等 30s）
- [ ] 系统字体调至最大：列表可滚、按钮 ≥ 约 44px 触控、编辑器可读
- [ ] 分屏 / 矮屏：底栏可隐藏文字仅图标；列表预览收敛
- [ ] 预测性返回：手势返回先关浮层/设置/编辑器，再双击退出
- [ ] 设置 → 命令面板 → 侧栏：返回键逐层关闭

## 壳层导航

- [ ] 底栏：笔记 | 任务 | 说说 | 我的
- [ ] 我的 → 搜索：全屏 Cmd-K 面板，关闭按钮可用
- [ ] 我的 → 资料库：无底栏/FAB，右上 × 回我的
- [ ] 资料库切换 文件/书库/媒体 分段控件
- [ ] 滚动隐栏：Tab 隐藏时迷你播放器贴底

## 主路径

- [ ] FAB / 全局「+」：笔记、说说、任务
- [ ] 桌面 Web：说说/任务为居中弹窗；Esc 关闭
- [ ] 任务「我的任务」空态 CTA
- [ ] 首页快捷：极简模块包下隐藏未授权入口

## 媒体与播放器

- [ ] 音频无封面占位正常
- [ ] 批量管理条贴底、不遮内容
- [ ] 迷你播放器与 Tab 间距

## 设置与偏好

- [ ] 启动落地页 / 模块包改后，换设备登录仍一致（云端偏好）
- [ ] 管理员站点闪屏 URL 生效（无本机自定义时）
