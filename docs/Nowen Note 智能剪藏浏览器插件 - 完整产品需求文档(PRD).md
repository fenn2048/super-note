## 一、项目概述

Nowen Note 智能剪藏插件是配套私有化Nowen笔记系统的浏览器扩展工具，支持全网网页智能剪藏，自动剔除广告、评论、推荐等无效干扰内容，一键将网页内容转为标准Markdown格式保存至个人笔记/说说。

插件支持**自定义私有化服务器地址、个人令牌鉴权、工作区分类、默认笔记本自动创建、图片智能压缩/本地化存储/过期自动清理**，完全适配个人NAS/本地/公网私有化部署，实现无侵入、高整洁、永久有效的网页收藏方案。

## 二、整体功能架构

插件整体分为六大核心模块：

1. **私有化配置模块**：自定义服务器地址、个人访问令牌、图片本地化开关

2. **资源分类模块**：工作区筛选、笔记本选择、默认剪藏笔记本自动创建

3. **智能剪藏模块**：整页智能剪藏、选区精准剪藏双模式

4. **全网净化模块**：通用干扰过滤 \+ 四大主流网站专属去广告规则

5. **图片高级处理模块**：自动压缩、本地化上传、外链替换、30天过期自动清理

6. **双端兼容模块**：Chrome / Safari 统一适配，API兼容垫片

## 三、详细功能需求

### 3\.1 私有化自定义配置模块（核心基础）

#### 3\.1\.1 服务器地址配置

- 支持用户手动输入：内网IP、localhost、公网域名、HTTPS地址

- 默认初始值：`http://localhost:3000`

- 输入实时持久化到浏览器本地缓存，永久保存

- 修改地址后自动重新校验接口、刷新工作区/笔记本列表

#### 3\.1\.2 个人访问令牌配置

- 用户填写 Nowen 系统「设置\-访问令牌」生成的个人令牌

- 令牌实时缓存，无需重复输入

- 令牌/服务器地址任一为空，所有功能按钮自动置灰禁用

- 令牌无效/过期/地址错误，提示连接失败，禁用所有操作

#### 3\.1\.3 图片本地化开关（可配置）

- 默认开启：剪藏图片自动上传至私有服务器，替换网页外链

- 关闭状态：保留原始网页图片外链，不上传服务器，节省磁盘空间

- 开关状态持久化缓存，用户一次设置永久生效

### 3\.2 工作区 \& 笔记本分类模块

#### 3\.2\.1 工作区选择功能

- 校验成功后，自动拉取当前用户所有工作区列表

- 默认选中第一个工作区

- 切换工作区，实时筛选刷新对应工作区下的笔记本列表

- 支持「全部工作区」选项，展示用户所有笔记本

#### 3\.2\.2 笔记本选择规则

下拉选项固定包含三类：

1. 💬 保存为说说：保存至用户说说，不关联笔记本/工作区

2. 📓 默认：剪藏笔记本：无指定笔记本，走默认自动创建逻辑

3. 用户自定义笔记本：当前工作区下所有个人笔记本列表

#### 3\.2\.3 默认笔记本自动创建核心规则（重点）

- 触发条件：剪藏类型为**笔记**，用户未手动选择具体笔记本

- 后端逻辑：检测当前用户名下是否存在名为「剪藏笔记本」的笔记本

- 不存在则**自动创建**，归属当前选中工作区

- 已存在则直接复用，不重复创建

- 所有默认剪藏内容统一归档，整洁统一

### 3\.3 双模式智能剪藏功能

#### 3\.3\.1 整页剪藏（智能净化）

- 基于 Mozilla Readability 智能识别网页正文

- 自动剔除页面所有干扰元素，只保留核心正文

- 自动转为标准规范 Markdown 格式

- 自动抓取正文图片、链接、标题

#### 3\.3\.2 选区剪藏（精准保留）

- 用户手动选中网页任意文本/内容

- 不执行智能净化，精准保留选中原始内容

- 直接转为Markdown保存
