# Super Note (弄文笔记) - UI/UX 交互与设计系统实现方案

> **项目定位**：轻量、安静、无压力的私有个人/家庭协作笔记工具。
> **设计目标**：通过高度定制化的主题皮肤（Skins）与柔和动效，降低用户高频记录的心理门槛，同时适配多端（Web/桌面端/移动端）响应式要求。
> **技术栈支撑**：Tailwind CSS (CSS 变量换肤) + Lucide Icons + Framer Motion (微动效)

---

## 一、 全局设计系统与 Token 规范 (Design Tokens)

为了实现一键切换多种视觉皮肤（Skins），系统并没有在 Tailwind 中写死具体的主题色值，而是采用**动态映射的 CSS 变量**。

### 1.1 边框圆角映射 (Roundness & Corner Radii)
圆角规则在 `tailwind.config.cjs` 中与以下三个核心 CSS 变量动态挂钩，各皮肤选择时自动进行覆盖：
*   `--radius-button`：映射至 `rounded-md`，决定按钮、小徽标和输入框的圆角。
*   `--radius-card`：映射至 `rounded-lg`，决定笔记卡片、待办项卡片和说说记录的圆角。
*   `--radius-window`：映射至 `rounded-xl` / `rounded-2xl`，决定设置模态框、弹出式抽屉和主内容区的圆角。

### 1.2 颜色系统变量
系统预留了 100+ 种语义化的 CSS 变量名，例如：
*   `--app-bg`：主画板/编辑器底色。
*   `--app-surface`：悬浮卡片、列表卡片的背景色。
*   `--app-border`：细边框与分隔线的颜色。
*   `--accent-primary`：品牌高亮主调（选中态、操作按钮）。
*   `--tx-primary` / `--tx-secondary`：主字色与次要说明字色。
*   `--app-hover` / `--app-active`：鼠标移入与点击时的背景色。

## 二、 五大核心皮肤视觉规范 (Visual Skins Spec)

### 2.1 Obsidian (默认暗黑)
*   **定位**：沉浸式、无干扰、保护视力的极客暗黑主题。
*   **圆角规范**：全硬角，`4px` geometric border-radius（按钮、卡片、窗口统一）。
*   **配色组合**：
    *   主背景色 (`--app-bg`)：碳黑 `#1e1e1e`（主编辑器）与侧栏暗色 `#161616`。
    *   高亮色 (`--accent-primary`)：暗夜紫 `#7a52f4` (暗色) / 优雅深紫 `#483699` (亮色)。
*   **视觉感官**：极致简约，纯平布局，无多余毛玻璃特效。

### 2.2 macOS (红苹果 HIG)
*   **定位**：遵循 Apple 官方 Human Interface Guidelines 的极简质感风格。
*   **圆角规范**：圆润圆角，按钮 `8px`，卡片 `10px`，窗口容器 `12px`。
*   **配色组合**：
    *   主背景色 (`--app-bg`)：浅灰 `#ececec` (亮色) / 沉静黑炭 `#1e1e1e` (暗色)。
    *   高亮色 (`--accent-primary`)：系统蓝 `#007aff` (亮色) / 苹果亮蓝 `#0a84ff` (暗色)。
*   **视觉感官**：带有半透明磨砂玻璃侧边栏 (Glassmorphism)，层次多级阴影，回弹物理感。

### 2.3 Notion (知识分子白)
*   **定位**：延续经典 Notion 风格的温润高质感排版体系。
*   **圆角规范**：硬朗微圆角，`4px` border-radius。
*   **配色组合**：
    *   主背景色 (`--app-bg`)：温暖牙膏白 `#ffffff` (亮色) / 纯暗黑 `#191919` (暗色)。
    *   侧边栏：暖灰 `#f1f1ef` (亮色) / 深冷碳 `#202020` (暗色)。
    *   高亮色 (`--accent-primary`)：知识蓝 `#2383e2`。
*   **视觉感官**：极细的边框，明朗清爽的留白，高知精英感。

### 2.4 Memos (slate 悬浮卡)
*   **定位**：轻快卡片式流式布局，专为短句记录设计。
*   **圆角规范**：适中圆角，按钮 `6px`，卡片 `8px`，窗口 `10px`。
*   **配色组合**：
    *   主背景色 (`--app-bg`)：冷灰石板 `#f3f4f6` (亮色) / 深石墨 `#121214` (暗色)。
    *   卡片底面 (`--app-surface`)：纯白 `#ffffff` (亮色) / 浮雕黑 `#1e1e24` (暗色)。
    *   高亮色 (`--accent-primary`)：薄荷绿 `#10b981`。
*   **视觉感官**：极具呼吸感，内容呈卡片在背景上悬浮，高对比高辨识。

### 2.5 flomo (水洗茶歇)
*   **定位**：温和的水洗绿底色配草绿色调，降低用户的提笔负担。
*   **圆角规范**：大圆角设计，按钮 `8px`，卡片 `10px`，窗口 `12px`。
*   **配色组合**：
    *   主背景色 (`--app-bg`)：水洗茶绿/奶油米黄 `#f4f4f0` (亮色) / 枯苔墨绿 `#181816` (暗色)。
    *   卡片底面 (`--app-surface`)：纯白 `#ffffff` (亮色) / 暖黑炭 `#252522` (暗色)。
    *   高亮色 (`--accent-primary`)：草绿 `#32b67a`。
*   **视觉感官**：极为护眼，主调温和，消除“面对白纸”的严肃抗拒感。

## 三、 响应式布局架构 (Responsive Layout Flow)

系统采用单代码流适配多端，基于媒体查询 (`md:`) 对桌面端和移动端执行两套完全不同的信息架构。

### 3.1 桌面端 (Desktop Layout)
```
┌─────────────────┬───────────┬───────────────┬───────────────────────────────┐
│                 │           │               │                               │
│  NavRail        │  Sidebar  │  Note List    │  EditorPane                   │
│  (模块导航轨道) │  (目录树) │  (搜索/列表)  │  (编辑器正文/说说发布/待办)   │
│  48px / 64px    │  ~240px   │  ~320px       │  flex: 1 (主编辑画板)         │
│                 │           │               │                               │
└─────────────────┴───────────┴───────────────┴───────────────────────────────┘
```
1.  **NavRail (模块导航轨道)**：
    *   系统的一级导航，最左侧常驻。包含“首页/笔记/说说/待办/思维导图/AI聊天/文件/消息/设置”等快捷图标。
    *   三档可见模式：`Icon` (纯图标, 48px)、`Label` (带字图标, 64px)、`Hidden` (完全折叠)。
    *   *安全自愈限制*：当主侧栏 (`Sidebar`) 也折叠时，NavRail 强制恢复显示，防止用户误触进入“双折叠”无法寻路的窘境。
2.  **Sidebar 与 Note List 双重拖拽宽度**：
    *   通过鼠标 Hover 出拖拽指示线进行实时宽度调整（Sidebar 限制 200px~450px，Note List 限制 250px~600px）。支持双击重置默认宽度。

### 3.2 移动端 (Mobile Layout)
1.  **底部 TabBar 结合 MobileTopBar**：
    *   底部 Tab 固定 5 项：“首页”、“笔记”、“说说”、“项目”、“更多”（拉起更多应用抽屉）。
    *   滑动手势触发隐藏：当用户在笔记列表或说说页向下滚动时，通过 `super:scroll-hide-bars` 自动将 TopBar 和 TabBar 移出屏幕边缘，向上微滚立刻呈现，最大化留给编辑器和阅读区。
2.  **MobileFAB 浮动发布按钮**：
    *   在笔记与说说主页底部常驻一个带毛玻璃虚化的多态发布按钮。点击展开“新建笔记/新建说说”的果冻过渡气泡动画。

## 四、 核心交互细节与手势方案

### 4.1 移动端滑动手势与防卸载拦截 (Swipe Gestures)
1.  **边缘滑动手势**：
    *   移动端支持从左屏幕边缘 30px 区域向右滑，一键唤出侧边栏抽屉；向左滑关闭抽屉。
2.  **`[data-swipe-blocker]` 机制 (关键设计)**：
    *   *问题背景*：由于手势在 document 顶层全局注册，当用户进入设置模态框或在滑动条上选择范围时，横向微划也会触发 `touchend` 关闭侧栏。因为 React Portal 渲染周期仍挂在 Sidebar 下，侧栏被卸载会导致正在设置的弹窗瞬间“白屏消失”，UX 体验极差。
    *   *解决方案*：使用自定义指令 `[data-swipe-blocker]`，在滑动手势事件冒泡判断中，若 `event.target.closest('[data-swipe-blocker]')` 不为空，则直接抛弃本次滑动手势，实现无侵入的局部手势锁。

### 4.2 说说模块的特殊组件设计 (Says UX)
1.  **朋友圈时间线 (Timeline Card)**：
    *   说说流采用单列卡片轻量布局，边框超细化。
    *   对于图片，单张图显示大比例、多张图呈九宫格自适应裁剪对齐。
2.  **语音播放器微动效 (Voice Player)**：
    *   带有音量物理感滑块和左右跳动均衡器 (EQ waves) 的 mini 语音气泡。播放时波形图根据播放进度以 SVG 遮罩过渡，视觉极其灵动。

### 4.3 表格编辑 UX 丝滑体验
1.  **网格选择器**：支持点击网格气泡菜单，以图形化网格矩阵拖拽行列数创建表格。
2.  **行高实时拖拽**：在表格行边缘提供加宽的 Hit Area 交互响应区，用户按住边缘拖动时，编辑区内浮现一条行高准星指示线，数据修改随 transaction 实时渲染同步至 ProseMirror 节点上。

### 4.4 命令面板 (Command Palette)
*   用户双击 `Cmd-K` (Mac) 或 `Ctrl-K` (Windows) 唤出搜索大弹窗，支持全拼/首字母搜索笔记、创建日记以及快捷命令切换皮肤。弹窗支持 Framer Motion 果冻弹性阻尼缩放弹出。
